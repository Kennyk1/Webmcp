        Welcome to Signal

        A task board built for people and agents to run together. Everything here is a real, working WebMCP integration — not a simulation.

        • Chat with the agent in the main window — ask it to check overdue tasks, search, or update things.
        • Reads run freely. Anything that changes data — marking tasks done, writing a file — waits for your explicit approval first.
        • Tool Forge lets the agent propose brand-new tools composed from existing ones. They only go live once you approve them.
        • Open the ☰ menu anytime to see the task board, every registered tool, proposed tools, and project files.
